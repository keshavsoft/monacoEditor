💡 Master Your Workspace

Monaco HTML Editor Guide

Everything you need to know about navigating, editing, and customizing your Monaco Editor environment.

🔤

Font Size Controls

Use the A- and A+ buttons in the header toolbar to scale editor text size live. The current font size is displayed in pixels and saved automatically.

📊

Live HTML Statistics

The bottom right status bar calculates live counts of IDs, Classes, and HTML Tags as you type code in real time!

📁

File Upload & Download

Click Upload HTML File to load any local .html file into the editor, or use Download File to save your changes instantly.

⚙️

Dedicated Settings Page

Click Settings to customize Theme (Dark/Light), Tab Size, Word Wrap, Line Numbers, and Auto-closing Brackets/Quotes. Preferences persist in local storage.

⌨️ Essential Keyboard Shortcuts

Boost your productivity with built-in Monaco Editor shortcuts.

Find & Replace Ctrl + F
Toggle Word Wrap Alt + Z
Format Document Ctrl + Shift + F
Trigger Suggestions Ctrl + Space
